## 核心工作：从单文件 main.js 迁移到标准 src/ 构建管线

仓库此前只有一份约 3370 行的手写 `main.js`，`src/` 仍是模板骨架（`TemplatePlugin`、空 `.gitkeep` 目录），构建管线产出的内容与线上插件完全无关。本次将真实插件逻辑完整迁移为 TypeScript 模块，使 `bun run build` 产出与手写版功能一致的插件。

### 模块划分（新 src/）

- `src/main.ts` — 入口，默认导出 `NeotreePlugin`
- `src/app/plugin.ts` — 插件主类（生命周期、事件、活动追踪、reveal、explorer 增强）
- `src/app/constants.ts` — 全部数值/行为常量与 `SPRING`
- `src/app/commands/index.ts` — 两条命令（切换文件夹刻度 / 切换拖动音效）
- `src/app/domain/orb.ts` — 小球/音效样式类型、归一化、解析、`STATIC_ORB_STYLES`
- `src/app/domain/orb-assets.ts` — 从 main.js 一次性提取的 SVG / base64 美术数据（勿手改）
- `src/app/services/activity.ts` — 活动记录纯函数（normalize / 磁吸排序 / 修剪 / 路径重写）
- `src/app/services/audio.ts` — `CrispAudio`（Web Audio 合成音效）
- `src/app/services/rail.ts` — `FileExplorerRail`（轨道 UI、拖动、滚动、音效触发）
- `src/app/settings/settings-tab.ts` — `CrispFileExplorerSettingTab`
- `src/app/types/` — `PluginSettings` / `RailItem` / `TickMark` 接口
- `src/app/utils/` — `dom.ts`（owner window/document 助手）、`math.ts`（弹簧/波形/二分）
- `src/styles.src.css` — 从根目录 `styles.css` 迁入并前置 `@import 'tailwindcss'`

### 修复的 bug

- `STATIC_ORB_STYLES` 在旧 main.js 中被使用但从未定义（非默认小球样式会导致 `ReferenceError`）；已在 `orb.ts` 中定义为空 Set（所有样式旋转），并留注释说明。
- `main.js` 中 `this.ticks.length`（容器 div 无 length，应为 `this.tickEls.length`）→ 修正为 `this.tickEls.length`。
- `tsconfig.json` 的 `ignoreDeprecations: "6.0"` 对 TS 5.9 非法 → 改为 `"5.0"`。
- 删除 `tsconfig.json` 中已弃用的 `baseUrl`（TS 6.x 会报弃用错，而项目锁定的 TS 5.9 又不接受 `ignoreDeprecations: "6.0"`）。本项目所有导入均为相对路径或 npm 包，`baseUrl` 无用；移除后编辑器（新 TS）与 CLI（锁定 TS）都能通过，且不再需要任何版本特定的 `ignoreDeprecations`。

### 决策

- 忠实移植逻辑，未在本次引入性能优化（transform 缓存、tickSideMap 清理、isVisible 缓存等留作后续）。
- `console.*` 错误路径统一走 `src/utils/log.ts`（生产构建中 console 被注释，符合社区评审要求）。
- 删除模板残留：`whats-new`/`support-links`/`buy-me-a-coffee` 及其测试、`md-modules.d.ts`、空 `.gitkeep`。
- 根目录 `main.js`、`styles.css` 为遗留/生成产物，已加入 `.gitignore` 语义并移出 eslint 检查；`git rm --cached main.js` 取消跟踪。

### 性能优化（行为不变）

- `render()`：缓存 orb 的 `translate3d` transform，仅在变化时写入（避免每帧样式写）。
- `renderOrbBall()`：缓存小球旋转 transform，仅在变化时写入；样式/禁用时重置缓存。
- `render()`：`tickSideMap` 仅非空时 clear。
- `isVisible()`：200ms 短缓存（`computeVisibility` 抽取）。
- `refresh()`：当元素集合与容器尺寸未变时复用上次的 item 中心点，跳过对所有条目 `getBoundingClientRect()`（大库下避免同步布局风暴）。
- `getTodayPathSet`/`getFrequentPathSet`/`getPinnedPathSet`：功能关闭时返回共享空 Set，不再每次分配。
