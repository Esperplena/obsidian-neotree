# Usage

The rail appears on the left edge of every file explorer pane. Grab the small orb
and glide it up and down to navigate your file tree.

## Getting Started

- **Drag** the orb to move it. The nearest row is highlighted.
- **Release** on a file to open it, or on a folder to expand/collapse it.
- Hold the orb over a **collapsed folder** to auto-expand it (optional).
- Hover near the top or bottom edge while dragging to **auto-scroll** the tree.

## Commands

| Command          | Description                                      |
| ---------------- | ------------------------------------------------ |
| `切换文件夹刻度` | Toggle whether folder rows are shown on the rail |
| `切换拖动音效`   | Toggle the drag tick sound                       |

## Features

- **Today trail** — faint dots mark every file opened today.
- **Smart magnets** — the orb gently snaps to pinned files and to files you open
  most often. Right-click any file → **Pin to Crisp Rail** to pin it (up to 8).
- **Daily random orb** — with the _daily random_ style, a new orb is picked each day.
