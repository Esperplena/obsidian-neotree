## 2.7.0

First release under the Neotree name. The codebase was migrated from a legacy
single-file bundle to the standard `src/` build pipeline (TypeScript modules +
Tailwind CSS), the plugin id/name were aligned with the community catalog rules,
and the documentation was rewritten.
